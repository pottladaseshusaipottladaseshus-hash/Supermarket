# Supermarket Sales Analysis

## Objective
Analyze supermarket transactions and identify the products and categories generating the most sales.

## Files
- `supermarket_sales.csv` - sales dataset
- `supermarket_analysis.py` - Python program
- `README.md` - documentation

## Analysis
- Calculate total sales.
- Compare sales by category.
- Compare sales by product.
- Display a product sales chart.

## How to Run
```bash
pip install pandas matplotlib
python supermarket_analysis.py
```
